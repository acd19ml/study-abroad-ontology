# 申请跟进与账号管理（需求整理）

- 依据：[2026-10-31 用户陈述](../sources/business-brief-2026-10-31-intake.md) R6、R7、R8、R9。
- 状态：业务方向已部分确认，字段、完整状态机、完成凭据与权限尚待定义；不代表进入建模或实现阶段。
- 当前用途：梳理完整业务中的辅助需求，用户尚未进入开发决策；本文件不是首期开发范围。

## 1. 申请和推荐信分别追踪（用户确认）

- 主申请记录“已递交申请”。
- 推荐人自行上传的推荐信单独记录“已确认上传”。
- 顾问手动递交推荐信单独记录递交状态，与推荐人自行上传路径区分。

当前不将“已递交申请”解释为推荐信全部完成，不将邀请发出解释为“已确认上传”。用户本轮偏好上述必要状态区分，未确认一套额外的多阶段推荐信状态机。

整理建议（待确认）：推荐信记录关联到具体学生、申请项目与推荐人，记录本次采用的递交方式、完成状态、确认时间及可取得的凭据。每项目需要几封、是否允许多种方式并用、是否需要再次上传，按具体项目再确定。

主申请、推荐信或其他材料之间的提交依赖，按具体项目核对；本草案不生成统一的“必须全部收齐才能递交主申请”规则。

## 2. 专用邮箱（用户确认）

- 每位学生建立申请专用邮箱。
- 顾问负责维护。
- 账号和密码需要记录。
- 邮箱账号和各学校网申账号分别记录关联关系（R8 确认）。
- 用户不要求实际密码加密保存（R8 确认）。

整理建议（待确认）：业务记录关联邮箱、所属学生、维护人和各校网申账号。按用户选择，不将密码加密列为既定要求；实际记录位置、可见权限和导出范围在架构阶段确定。需求文档目前仅记录管理方式，不包含真实密码。

目前仅记录管理需求，没有新建邮箱、读取邮件、保存真实密码或登录学校系统。网申实际操作者、邮箱最终交接和监控接入方式待明确。

## 3. 中文核对稿到英文稿（用户确认）

1. 顾问整理、编辑中文稿，学生核对。
2. 中文稿确认后，AI 生成英文稿。
3. 如需调整经历，修改中文稿后重新生成英文稿。

用户进一步确认 AI 辅助检查、顾问最后确认，并明确 AI 应主动获取项目要求、调用客户背景、组装上下文和受约束执行，详见[自主工作需求](agent-autonomy-requirements.md)。

整理建议（待确认）：英文稿关联其依据的中文版本；修改中文经历后，原英文稿标记为待更新；实际递交时记录所用版本。中文变更重新确认、要求采纳与版本归档的具体办法尚未决定。

## 4. 邮件跟进（职责已确认，细则待讨论）

用户已确认：邮件到达后判断是否与申请有关、识别对应业务事件、分类并形成待办；提醒与待办只发给顾问。

处理链候选：收到邮件 → 判断相关性 → 关联学生与项目 → 识别事件 → 提取行动项 → 形成顾问待办与提醒。学生可通过专用邮箱关联，具体项目关联方式尚未确定。

### 邮件事件类别（用户已同意）

- 申请回执与进度通知：默认供顾问知悉；邮件另有要求时提取行动项。
- 补充或更正材料要求：提取所需材料、操作要求和原文中的截止信息。
- 推荐信相关通知：识别待推荐人处理或上传进度，与主申请状态分开。
- 面试或其他评估邀请：提取预约、确认、准备或参加要求。
- 申请结果：区分录取、有条件录取、候补、拒绝等标签，结果变化是否写入业务状态另定。
- 接受录取、缴费或满足后续条件的通知：按原文提取实际行动与时限。
- 一般宣传或非申请邮件：记录相关性判断，默认不生成行动任务。
- 无法判断：保留原文和具体疑问，交顾问判断；没有明确截止时间时保持未知（用户确认）。

上述类别由用户同意作为业务分类，尚未用真实邮件校验，不代表所有学校共同的通知分类或要求。用户已确认同封邮件多个要求分别提取，事件与待办分别记录。

### 事件与待办的区别（原则已确认，示例用于说明）

- “收到申请回执”可以仅为进度信息；若无行动要求，可不创建行动待办。
- “收到补件要求”是识别到的业务事项；“补交成绩单”是需要跟进的行动。
- 用户确认纯通知可没有行动待办，同一封邮件有多个行动要求时分别提取。
- 分类结果、待办创建、任务完成、申请结果确认分别记录；不从邮件已读推断任务已完成。
- 邮件原文是外部信息来源；识别出的业务事项与已生效模型事件区分，具体导入或确认命令在建模阶段定义。

### 异常判断（用户已确认）

- 识别不确定时保留原文和具体疑问，交顾问判断。
- 未明确的截止时间保持未知，不补成确定日期。

### 与录取后服务的关系

用户已明确申请事务中录取后提供留位费提醒、补交材料，其他留学后续事务不提供；12 个月求职服务单独保留。需要时顾问可与学校邮件交涉，一般询问及既有事实说明自行处理，涉及客户意愿或承诺时先取得客户决定。系统负责邮件分类与顾问待办，顾问对外沟通权限不能推导为系统自动发信权限。

### 后续业务细则

- 待办如何跟进与确认完成，项目关联不明时的具体核对方式。
- 哪些情况立即提醒、哪些汇总；提醒渠道、周期、截止时间与时区解释。
