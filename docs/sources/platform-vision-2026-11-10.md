# 平台形态与多租户的长期方向

- 日期：2026-11-10。
- 来源：用户讨论开发流程时的陈述。

## 用户原话

“我这个产品最终应该要交付一个留学申请的服务平台，我在想需要有给服务对象呈现的内容，还有顾问（我）要用到的视图，甚至我以后想支持多租户，将该软件平台的服务提供给其他留学机构。”

## 要点

- 最终交付物是一个留学申请服务平台。
- 平台至少有两类视图：给服务对象（学生、家长）呈现的内容，以及顾问使用的视图。
- 以后可能支持多租户：把平台作为服务提供给其他留学机构。
- 与已确认事实的关系：当前系统只由顾问个人使用、客户不操作（B8）；上述内容是长期方向，不改变当前阶段的范围。
