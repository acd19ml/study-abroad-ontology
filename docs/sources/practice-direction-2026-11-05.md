## 要点

- 原来的做法：先定一个大一统的标准和消费方式，再把原始信息挖掘进标准，期望通用地解决所有问题。问题是操作困难，难以验证。
- 新的路径：
  1. 梳理需求；
  2. 构建金标测试集（golden test set）；
  3. 分析如何定义业务本体模型标准；
  4. 根据金标的消费效果，决定用什么形态承载和消费业务知识。
- 用户要沿这条路径实践，并在实践中持续修订实践标准。
