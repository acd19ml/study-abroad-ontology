## 服务对象与交付

- PDF p1：2027 年秋季香港授课型硕士申请，附求职指导与职业规划；不能直接扩展至其他地区和学位。
- PDF p1：选校定位、申请策略、实习方向规划和申请 CV。
- PDF p1–2：CV 定制，至少初稿加两轮修改；符合具体优化意见等条件时可额外最多两轮，再增加需协商。
- PDF p2：每个申请项目分别定制 PS；修改机制参照 CV。
- PDF p1–2：收到明确具体意见后 3 个工作日内反馈修改；客户收到修改稿后 5 个工作日内反馈或确认，超期未说明有视为认可的约定。
- PDF p2–3：入学面试准备、材料清单与格式指导、至少一次完整性和一致性核查；流程或信息变更时补充指导与核查。
- PDF p3：申请项目数量不限；另含求职简历、求职面试与长期职业规划。
- PDF p3：质量要求涉及题目回应、字数格式、真实背景、项目匹配、语言与结构；未将录取或求职结果作为交付标准。
- PDF p4：收到全部已申请院校最终结果时第一阶段完成；第二阶段自该日起持续 12 个月。

## 确认、付款和终止相关事实

- PDF p2：申请材料、PS、CV、申请信息经客户最终确认后提交。
- PDF p4：客户负责提供真实、完整资料并参与核对；客户有院校专业最终决定权和进度知情权。
- PDF p3–4：总价 10,000 元，两期各 5,000 元；首期签订起 3 个工作日内支付。
- PDF p4：第二期在首个项目 PS 与申请 CV 定稿交付并获书面确认、或首个网申正式提交两种情形中较早发生后 3 个工作日内支付。
- PDF p4：另约定定稿收到后 7 个工作日未提出具体意见且未书面确认时的付款触发；与修改稿 5 日反馈约定不是同一事件。
- PDF p3：申请、考试等第三方费用由客户承担，有提交后提供缴费截图、据实结算的约定。
- PDF p5–6：解除时按已完成服务核算；已开始未完成项涉及 50%～100% 的工作量判断；退款金额双方确认后 7 个工作日内完成。

## 待访谈确认的差异和歧义

- 未来四地服务是否继续沿用该版交付、数量、时限、价格和求职服务；现稿与未来套餐应分别记录。
- “申请项目不限”与逐项目定制、多轮修改、长期求职服务组合下的个人服务容量。
- 推荐信、课程论文素材整理、项目或实习具体辅导、雅思教师推荐与成绩跟踪、邮箱自动监控、咨询话术未在本版中明确为对应交付。
- PDF p2 的指导填写提交与 p3–4 的顾问提交表述，需要明确实际操作者、账户归属和最终确认方式。
- 反馈认可、文书定稿、客户最终提交确认和付款触发应作为不同候选业务事实；不能因超期反馈直接推断已取得提交授权。
- “明确可优化空间”“必要补充”“完成工作量”等暂列人工判断候选。
- 语言条件在 PDF p4 被提及为客户负责的前置条件，并没有形成所有学校均须雅思达标才可网申的统一规则。
- “同样材料由谁提交都一样”的宣传观点没有由本合同证明，仍待针对适用场景核验。
- PDF p5 的客户素材使用条款需在后续明确：客户原始资料、脱敏案例、话术知识的再利用范围与授权记录。

正式规则的约束强度、动作、例外、负责角色及实现位置，均留待业务确认和建模阶段定义。
