# 用例路径清单 v0.1

- 状态：Agent 起草，待用户审阅。
- 来源：[产品需求文档 v0.1](../../docs/requirements/product-requirements-v0.1.md) 的用户故事与验收标准。
- 用途：作为金标测试集的覆盖骨架。每条路径至少对应一道题（见[构建标准](README.md)第 8 节）。
- 类型：主 = 主流程；备 = 备选流程；异 = 异常流程。
- 第一批题目覆盖首个场景（PS 准备）直接依赖的路径；“待出题”的路径在后续批次补齐。
